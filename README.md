# عقل × هبد 🧠✖️🗣️

لعبة جماعية قائمة على التحدي والضحك، بتجمع بين التفكير المنطقي والهبد الابتكاري!

## 🎮 أقسام اللعبة
- **تشغيل دماغ 🧠:** ألغاز وخدع منطقية تحتاج تركيز.
- **هبد في هبد 🗣️:** أسئلة ملهاش إجابة علمية، والنقطة لأكتر إجابة مقنعة أو بتضحك.
- **خمن الصورة / الإفيه 🎬:** تكملة إفيهات الأفلام والمشاهد الشهيرة.
- **أسئلة عامة 📚:** معلومات عامة وثقافة سريعة.

## 🏆 طريقة الفوز
أول لاعب يجمع **5 نقاط عقل + 5 نقاط هبد** يفوز بلقب **"المفكر الهاباد"**!

## 🛠️ التكنولوجيا المستخدمة
- HTML5 / CSS3 / JavaScript
- استضافة مجانية عبر GitHub Pages
